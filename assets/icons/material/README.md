# Material Symbols

These 24 px Outlined SVGs come from Google's
[`material-design-icons`](https://github.com/google/material-design-icons)
repository and are licensed under the Apache License 2.0. Only symbols used by
the theme are vendored. Keep filenames aligned with their official symbol names
and render them through `layouts/partials/material-icon.html`.

Add missing symbols with `npm exec -- piatto icon add <name...>`. The command
supports the standard `HTTPS_PROXY`, `HTTP_PROXY`, and `NO_PROXY` environment
variables (including lowercase forms), or an explicit `--proxy <url>` option.
